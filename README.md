# AutoLite — Fast Key Extractor

Automates the streamfiles.eu.org → vidyarays.com article chain to extract an access key.

## Setup (Arch Linux)

```bash
bash setup.sh
```

Manual install if preferred:
```bash
sudo pacman -S chromium          # includes chromedriver
pip install --break-system-packages curl_cffi beautifulsoup4 selenium
```

## Workflow

### Step 1 — Harvest CF cookies (once per ~30 min)
```bash
python cookie_helper.py
```
Opens Chrome. Both domains load automatically. Solve any CF challenge manually if it appears. Press Enter when done. Saves `cf_cookies.json`.

### Step 2 — Run the extractor
```bash
python fastscript.py
```
Loads cookies, runs the full chain, prints the access key URL.

---

## How it works

```
cookie_helper.py
  └─ Selenium (real Chrome) → harvests cf_clearance cookies
       └─ cf_cookies.json

fastscript.py
  └─ curl_cffi (Chrome TLS impersonation)
       ├─ Inject CF cookies
       ├─ GET streamfiles.eu.org/task-verify.php
       ├─ POST action=generate
       │    └─ 302 redirect → r.url = vidyarays.com/prolink.php?id=XXX
       ├─ GET prolink URL (sets session state)
       ├─ GET vidyarays.com/ with Google referer
       │    └─ parse homepage → first article URL
       └─ POST article chain (dynamic — each response decodes to next URL)
            └─ Final decoded URL = streamfiles.eu.org/task-verify.php?access_key=JWT
```

## Key design decisions

**Why `r.url` not HTML extraction for prolink:**
The generate POST returns an HTTP 302 redirect to `vidyarays.com/prolink.php?id=XXX`. curl_cffi follows it. `r.url` after the POST is the prolink URL. The HTML content is the countdown page on vidyarays.com — it doesn't contain the prolink URL.

**Why no hardcoded article URLs:**
The chain is session-specific, assigned server-side via the prolink `?id=`. It can rotate. The script discovers URLs dynamically — each article POST decodes to the next URL.

**Why two CF cookies:**
streamfiles.eu.org and vidyarays.com are separate CF zones. Each requires its own `cf_clearance`.

## Files

| File | Purpose |
|---|---|
| `fastscript.py` | Main extractor (curl_cffi, fast) |
| `cookie_helper.py` | CF cookie harvester (Selenium) |
| `netcap.py` | Network capture tool for flow analysis |
| `cf_cookies.json` | Saved CF cookies (generated by cookie_helper) |
| `requirements.txt` | Python dependencies |
| `setup.sh` | Arch Linux one-shot setup |

## Troubleshooting

**"cf_clearance missing"** → Re-run `python cookie_helper.py`

**"No article links found on homepage"** → The homepage HTML changed. Run `python netcap.py`, complete the full flow, then check the article POST chain in the output to see current URLs.

**"chromedriver not found"** → `sudo pacman -S chromium` on Arch. chromedriver is bundled.

**CF challenge appears in cookie_helper** → Solve it manually in the Chrome window that opened. The script waits.
